How it works

Evidence first. Reputation later.

1
CollectRead public PR metadata, commits, reviews, and CI checks.
2
CanonicalizeRecursively sort object keys while preserving array order.
3
HashGenerate a Keccak-256 evidence hash and deterministic source ID.
4
AnchorRegister the evidence snapshot in BaseProofRegistry on Base.
A proof shows that a verifier anchored a specific evidence snapshot. It is not an automatic quality score or a claim that GitHub itself attested the proof.
